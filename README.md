# 기분 측정표 (BiEval)

기분의 변화를 매일 기록하고 표와 그래프로 확인하는 웹 앱입니다. 양극성장애를 기본 대상으로 하지만, 기분 변동(mood coloring)이 있는 경우라면 누구나 사용할 수 있습니다. 화면 구성과 사용 방식은 [DepEval](https://github.com/mrnoh99/DepEval), [PainEvaluation](https://github.com/mrnoh99/PainEvaluation)의 웹 앱을 따르며, 외부 라이브러리나 빌드 과정 없이 순수 HTML/CSS/JavaScript로 작성되어 있습니다.

## 구성 (2개 탭)

### 1. 기분 기록 — 하루 한 번
각 항목을 **0~10점** 슬라이더로 기록합니다.

| 항목 | 내용 |
| --- | --- |
| 우울 | 그날 느낀 우울감의 최고(가장 심했던) 정도 |
| 고조 / 경조증·조증 | 기분이 들뜨거나 과도하게 활기찬 고조 상태의 정도 |
| 짜증 | 예민함이나 분노, 격앙된 짜증의 정도 |
| 불안 | 불안감이나 초조함의 정도 |
| 에너지 레벨 | 그날의 신체적·정신적 활동 에너지 수준 |

- **수면**: 잠든 시간(시:분)과 총 수면시간(시간, 0.5 단위) — 비워 둘 수 있습니다.
- **메모**(선택): 약 변경, 중요한 사건 등 한 줄 기록
- 하루에 한 건: 이미 기록한 날짜를 고르면 그 기록을 불러와 수정할 수 있고, 저장 시 확인 후 덮어씁니다.
- 기본값은 증상 항목 0점, 에너지 5점입니다.

### 2. 결과 분석
- **그래프**: 이중 축 선 그래프 — 왼쪽 축(0~10) 기분 5항목, 오른쪽 축 총 수면시간(점선)
  - 범례의 체크박스로 항목을 켜고 끌 수 있습니다(2개 이하로 켜면 값이 숫자로 표시됩니다).
  - 한 손가락 드래그로 좌우 이동, 두 손가락 핀치로 간격 조절, ＋ / − / 기본 버튼
  - 기본으로 한 화면에 세로 7개 / 넓은 화면(600px 이상) 14개 표시
- **요약**: 최근 7일 · 최근 30일 · 전체 기간의 항목별 평균과 평균 수면시간

## 데이터
- 기록은 브라우저의 `localStorage`에만 저장됩니다(서버 전송 없음).
- **JSON 백업 / 복원**: 복원은 현재 기록에 병합하며, 이미 기록이 있는 날짜는 건너뜁니다.
- **CSV 저장 / 메일**: 날짜순 CSV(Excel용 BOM 포함). 모바일에서는 공유 시트로 메일에 첨부합니다.

## 실행
- **로컬**: `web/index.html`을 브라우저에서 엽니다.
- **GitHub Pages**: `.github/workflows/deploy-pages.yml`이 `web/` 폴더를 배포합니다.
  최초 1회 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 지정해야 하며, 이후 `https://mrnoh99.github.io/BiEval/`에서 접속합니다.
- **PWA**: 홈 화면에 추가해 앱처럼 설치하고 오프라인에서도 사용할 수 있습니다.

## 파일
```
web/
├── index.html            # 2개 탭 화면 구조
├── styles.css            # 스타일 (라이트/다크 자동)
├── app.js                # 항목, 저장, 그래프, 내보내기/가져오기
├── manifest.webmanifest  # PWA 매니페스트
├── sw.js                 # 서비스워커 (네트워크 우선 + 오프라인 캐시)
└── icons/
```

항목을 바꾸려면 `web/app.js` 상단의 `ITEMS` 배열을 수정하면 됩니다.

> 이 앱은 자가 기록 도구이며 진단을 대신하지 않습니다.
